# 网吧管理系统

本项目为一套基于 **Vue3 + Vite** 前端与 **Node.js + Express + MySQL** 后端的网吧管理系统，支持上机、下机、充值、退费、卡片管理及多维度统计分析。系统界面美观，交互友好，功能完善，适合中小型网吧日常管理与数据统计需求。

## 主要功能

- **卡片管理**：新办卡、查询、注销、删除等操作。
- **上机/下机管理**：记录用户上机、下机时间及消费金额。
- **充值/退费**：支持自定义金额的充值与退费，所有操作均有日志记录。
- **统计分析**：
  - 支持按卡号、按天、按类型（消费/充值/退款）多维度统计。
  - 统计结果分组展示，明细与总计一目了然。
  - 统计页面支持响应式布局与美观的表格展示。
- **页面美化与布局优化**：
  - 采用渐变背景、圆角卡片、阴影、动画等现代UI设计。
  - 支持响应式，适配不同屏幕。
  - 侧边菜单与主内容区分离，操作便捷。

## 技术栈

- **前端**：Vue 3、Vite、Vue Router、Axios、Day.js、CSS3
- **后端**：Node.js、Express、MySQL2、CORS、Body-Parser
- **数据库**：MySQL

## 一键部署与运行

本项目已支持一键自动化部署，无需手动配置数据库或分别安装依赖。只需按照以下步骤操作：

### 环境准备

1. 安装 [Node.js](https://nodejs.org/)。
2. 安装 [MySQL](https://dev.mysql.com/downloads/installer/)。
3. （可选）安装 [Git](https://git-scm.com/) 用于拉取项目代码。

### 获取项目代码

- 通过 Git 克隆项目（推荐）：
  ```bash
  git clone https://github.com/bestVictor2/FirstVue.git
  ```
- 或直接下载压缩包并解压。

### 一键启动

1. 打开命令行（cmd 或 PowerShell）。
2. 进入项目根目录，例如：
   ```bash
   cd /c/Users/你的用户名/Desktop/cvue
   ```
3. 运行批处理文件：
   ```bash
   start_all.bat
   ```
4. 按提示在终端输入你的 MySQL 用户名和密码。
5. 程序会自动：
   - 安装所有依赖（根目录、后端、前端）
   - 初始化数据库（自动建库建表）
   - 启动后端和前端服务
   - 自动打开前端网页（http://localhost:5173）

### 常见问题

- **数据库连接失败**：请确认 MySQL 服务已启动，用户名和密码输入正确。
- **端口被占用**：请关闭占用 3000（后端）或 5173（前端）的程序，或修改端口配置。
- **依赖安装失败**：请检查 Node.js 是否安装，网络是否正常。

如有其他问题，请参考命令行输出的提示信息，或联系开发者。

## 特色与亮点

- **自定义金额**：充值、退费金额可灵活输入，默认无初始值，防止误操作。
- **分组统计**：统计页面支持按卡号分组，明细与总计并列展示，便于管理。
- **美观易用**：采用现代化UI设计，交互流畅，支持移动端适配。
- **代码规范**：前后端分离，接口清晰，易于维护和扩展。
- **分支管理**：推荐使用 Git 分支进行功能开发，保障主分支稳定。

## 适用场景

- 网吧、电竞馆等需要对上机、充值、消费、退费等进行精细化管理的场所。
